# 모바일 명함 · 강지명 (Corelink)

블랙 & 골드 톤의 모바일 최적화 디지털 명함. GitHub Pages 로 서비스한다.

**라이브:** https://ji-myung.github.io/corelink-mobile/

## 기능

- 연락처 저장 (vCard `.vcf`), 전화 걸기, 카카오톡 상담 연결
- 전화번호·이메일 한 번 탭 복사
- 인스타그램 / 유튜브 / 홈페이지 링크
- QR 코드 영역, 명함 링크 공유 (Web Share API)
- 다크 / 라이트 테마 토글 (기본 다크)

## 개발

```bash
npm install
npm run dev
```

콘텐츠 수정은 `src/data/profile.ts` 한 곳에서 한다. 자세한 규칙은 `CLAUDE.md` 참고.
